# IoT Weather Station

An IoT-based weather monitoring system that collects environmental data using a BME280 sensor connected to a microcontroller.

## Features

* Temperature and environmental data collection
* BME280 sensor integration
* Automated sensor data processing
* Embedded Python-based implementation

## Technologies

* Python / MicroPython
* BME280
* IoT
* Embedded Systems
* Sensor Interfacing
